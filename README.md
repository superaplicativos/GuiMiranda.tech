## SEO / AEO / GEO
- HTML semântico, 6 páginas otimizadas (titles, metas, canonical, Open Graph, Twitter Cards)
- JSON-LD: `ProfessionalService`, `Person`, `WebSite`, `Course`, `Product`/`Offer`, `FAQPage` (18 perguntas), `BreadcrumbList`, `ContactPage`, `AboutPage`
- `sitemap.xml` e `robots.txt` na raiz
- Imagens em WebP com fallback JPG, fonts `display=swap`, JS `defer` (Core Web Vitals)
- Local SEO: Ribeirão Preto (geo, placename, areaServed)

## Domínio próprio (guimiranda.tech)
Ao apontar o DNS, adicione um arquivo `CNAME` contendo `guimiranda.tech` e configure em Settings → Pages → Custom domain, atualizando `canonical`/`og:url`/`sitemap.xml` para a URL final.
